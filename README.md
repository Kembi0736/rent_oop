# rent_oop

Система учёта аренды инструментов для мастерской: перфораторы, шлифмашинки, лестницы. Клиент оставляет заявку, вносит залог и берёт инструмент на время; оператор выдаёт, принимает обратно, проверяет дефекты и возвращает залог.

Язык реализации: C#

## Структура репозитория

| Путь | Содержание |
|---|---|
| `specification/` | Неполная спецификация: словарь терминов, процессы, права ролей, сценарии, открытые вопросы |
| `diagrams/` | Схемы Mermaid и свод принятых решений D1–D14 |
| `spec/04-модель.md` | Объектная модель, правила и инварианты, состояния, контракты операций |
| `decisions/` | Записи решений (ADR) по шаблону `000-шаблон.md` |
| `agent-log.md` | Текст требования, вопросы/допущения и журнал обращений к ИИ-агенту |
| `роли.md` | Анализ полномочий ролей: оператор и клиент |

## Диаграммы

| Файл | Схема |
|---|---|
| `diagrams/01-классы.md` | `classDiagram` |
| `diagrams/02-состояния.md` | `stateDiagram-v2` (заявка, единица, аренда) |
| `diagrams/03-последовательность.md` | `sequenceDiagram` (успешная аренда, отклонение, дефект) |

Над каждой схемой — вопрос, на который она отвечает. GitHub отображает Mermaid в `.md` автоматически; при изменении схемы можно проверить её в [Mermaid Live Editor](https://mermaid.live) перед коммитом.
