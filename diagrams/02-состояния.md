# Диаграммы состояний

## Заявка

**Вопрос:** Через какие состояния проходит заявка и кто их меняет?

```mermaid
stateDiagram-v2
    [*] --> ОжидаетОбработки : клиент оставляет заявку

    ОжидаетОбработки --> ЗалогВнесён : клиент вносит залог
    ОжидаетОбработки --> Отклонена : оператор отклоняет

    ЗалогВнесён --> Обработана : оператор подтверждает заявку
    ЗалогВнесён --> Отклонена : оператор отклоняет

    Обработана --> Закрыта : выдача инструмента (начало аренды)

    Отклонена --> ЗалогВозвращён : залог возвращается полностью
    ЗалогВозвращён --> [*]

    Закрыта --> [*]

    note right of Отклонена
        Решение D7: отклонение — только
        оператором, до выдачи инструмента.
        Залог возвращается в момент отклонения.
    end note
```

## Единица инструмента

**Вопрос:** В каких состояниях бывает единица инструмента и что переводит её из одного состояния в другое?

```mermaid
stateDiagram-v2
    [*] --> Свободен

    Свободен --> ВАренде : выдача по заявке
    ВАренде --> Свободен : приём, дефектов нет

    ВАренде --> Неисправен : приём с дефектом (D12)
    Свободен --> Неисправен : дефект выявлен при проверке

    Неисправен --> Свободен : ремонт завершён
    Неисправен --> Списан : не подлежит ремонту

    Списан --> [*]

    note right of Неисправен
        Решение D12: учёт ремонта введён.
        Допущение 11 agent-log.md («статусов
        меньше трёх») пересмотрено.
    end note
```

## Аренда

**Вопрос:** Как проходит полный цикл аренды — от выдачи инструмента до возврата залога?

```mermaid
stateDiagram-v2
    [*] --> Активна : выдача инструмента (оплата принята)

    Активна --> Завершена : приём, дефектов нет
    Завершена --> [*] : залог возвращён полностью (одно действие, D13)

    Активна --> Завершена : приём с дефектом (D13)
    Завершена --> ЧастичныйВозврат : удержано за дефект
    ЧастичныйВозврат --> [*] : возвращён остаток залога

    note right of Завершена
        Решение D13: приём инструмента и
        возврат залога — одно действие
        оператора. При дефекте залог
        делится: удержание + возврат.
    end note
```
