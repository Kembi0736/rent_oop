# Диаграмма классов

**Вопрос:** Какие классы участвуют в учёте аренды инструментов и как они связаны между собой?

```mermaid
classDiagram
    direction LR

    class Клиент {
        +имя
        +контакт
        +оставитьЗаявку()
        +внестиЗалог()
        +вернутьИнструмент()
    }

    class Оператор {
        +обработатьЗаявку(заявка, решение)
        +выдатьИнструмент(заявка)
        +принятьИнструмент(аренда, дефекты)
        +проверитьДефекты(единица)
        +вестиУчёт(единица, состояние)
    }

    class Заявка {
        +статус
        +датаНачала
        +датаОкончания
        +обработать(решение)
        +отклонить()
    }

        +сумма
        +внесен
        +внести()
        +вернуть()
    }

        +датаВыдачи
        +датаВозврата

        +завершить(дефекты)
    }

        +сумма

    }

        <<тип>>
        +наименование
        +ставка24ч
        +размерЗалога
    }

    class ЕдиницаИнструмента {
        +инвентарныйНомер

    }

        +описание
        +суммаУщерба
    }

    class Запись {

        +событие
        +данные
    }

    Клиент "1" --> "0..*" Заявка : оставляет
    Клиент "1" --> "0..*" Залог : вносит
    Клиент "1" --> "0..*" Аренда : пользуется

    Заявка "1" --> "1" Инструмент : на
    Заявка "1" --> "0..1" Залог : обеспечивается

    Аренда "1" --> "1" ЕдиницаИнструмента : предмет
    Аренда "1" --> "1" Залог : покрывается
    Аренда "1" --> "0..1" Оплата : оплачивается
    Аренда "1" --> "0..*" Дефект : может иметь

    Оплата "1" --> "1" Инструмент : по типу

    ЕдиницаИнструмента "0..*" --> "1" Инструмент : относится к типу

    Оператор "1" --> "0..*" Заявка : обрабатывает
    Оператор "1" --> "0..*" Аренда : выдаёт и принимает
    Оператор "1" --> "0..*" Дефект : фиксирует
    Оператор "1" --> "0..*" Запись : создаёт

    Запись "0..*" --> "1" Аренда : отражает
```

## Пояснения к элементам

| Элемент | Пояснение |
|---|---|
| `Инструмент` / `ЕдиницаИнструмента` | Тип и конкретный экземпляр разделены — решение **D1** (ADR-001 в `decisions/`). |
| `Заявка.статус` | Статусы зафиксированы решением **D2**: `ОжидаетОбработки → ЗалогВнесён → Обработана → Закрыта`, ветка `Отклонена`. |
| `Заявка.датаНачала/датаОкончания` | Срок в сутках, максимум 14 + продление до 7 — решение **D3**. |
| `Залог.сумма` | Фиксирована по типу инструмента: 3000/2000/1500 ₽ — решение **D4**. |
| `Залог.вернуть()` | Возврат — полномочие оператора — решение **D5**. |
| `Оплата` | Плата за аренду отдельно от залога, принимается при выдаче — решение **D8**. |
| `Дефект.суммаУщерба` | Удержание не превышает залог (инвариант I14), излишек моделью не учитывается. |
| `Запись` | Журнал только пополняется — решение **D9**, инвариант I17. |

Роли по таблице прав: рабочие — только `Клиент` и `Оператор` (D10). Полный список решений D1–D14 — в `diagrams/diagrams.md`.
