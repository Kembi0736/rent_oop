## Объекты

| Объект | Идентичность | Атрибуты | Ссылки |
|---|---|---|---|
| **Клиент** | имя + телефон (D14) | имя, телефон | → свои заявки (0..*), свои аренды (0..*) |
| **Оператор** | учётная запись | — | → обрабатываемые заявки, аренды, дефекты, записи журнала |
| **Заявка** | порядковый номер | статус (D2), датаНачала, датаОкончания | ← клиент (1); → тип инструмента (1); → залог (0..1) |
| **Залог** | привязан к заявке | сумма, признак «внесён» | ← заявка (1); ← клиент, внёс |
| **Оплата** | привязана к аренде | сумма, дата | ← аренда (0..1); → тип инструмента (ставка) |
| **Аренда** | порядковый номер | датаВыдачи, датаВозврата, стоимость | ← заявка закрытая (1); ← клиент (1); → единица (1); → залог (1); → оплата (0..1); → дефекты (0..*) |
| **Инструмент (тип)** | наименование: перфоратор / шлифмашинка / лестница | ставка24ч (D8), размерЗалога (D4) | ← единицы (0..*); ← заявки; ← оплаты |
| **ЕдиницаИнструмента** | инвентарный номер | состояние (D12) | → тип (1); → активная аренда (0..1) |
| **Дефект** | порядковый номер в аренде | описание, суммаУщерба | ← аренда; ← оператор (зафиксировал) |
| **Запись (журнал)** | порядковый номер | дата, событие, данные | ← аренда; ← оператор (создал) |

Роли по таблице прав — только `Клиент` и `Оператор` (D10).

## Правила и инварианты

| Правило | Владелец | Инвариант | Когда проверяется |
|---|---|---|---|
| Одна единица — одна активная аренда | `ЕдиницаИнструмента` | I1: `∀e: |{a : a.единица = e ∧ a.активна}| ≤ 1`; I2: `состояние = ВАренде ⇔ есть активная аренда`; I16: `Неисправен/Списан` ⇒ нет активной аренды | При выдаче и приёме — в момент смены состояния |
| Выдача только свободного | `ЕдиницаИнструмента` | I3: выдача возможна только из состояния «Свободен»; I4: при 0 свободных единицах типа выдачи по заявкам на тип невозможны | Перед созданием аренды |
| Полная готовность выдачи | `Аренда` | I5: выдача ⇔ заявка `Обработана` ∧ залог внесён ∧ оплата принята (всё одновременно) | В момент выдачи |
| Один залог — один возврат | `Залог` | I6: ≤ 1 внесённого залога на заявку; возврат ≤ 1 раза; только после отклонения или приёма инструмента | При внесении и при возврате залога |
| Баланс денег по залогу | `Залог` | I7: `удержание + возврат = залог`, `0 ≤ удержание ≤ размерЗалога`; при отсутствии дефектов удержание = 0; I14: `суммаУщерба ≤ размерЗалога` | При возврате залога, в том числе с дефектом |
| Цена и срок аренды | `Аренда` | I8: `стоимость = ставка24ч × сутки`, `1 ≤ сутки ≤ 21` (14 + продление до 7, D3); I9: залог и оплата независимы, не компенсируют друг друга | При выдаче (расчёт стоимости) и при продлении |
| Порядок статусов заявки | `Заявка` | I10: переходы только по схеме, назад нельзя; `Закрыта`/`Отклонена` — терминальные; I11: отклонение только до выдачи; I12: `Закрыта` ⇔ ровно одна аренды, порождённая заявкой | При каждом изменении статуса |
| Дефекты фиксируются всегда | `Дефект` | I13: проверка при выдаче и приёме обязательна (D11); каждый дефект — ровно одна запись с `суммаУщерба`; I15: приём = завершение аренды = возврат залога одним действием (D13) | При осмотре на выдаче и на приёме |
| Журнал неизменяем | `Запись` | I17: записи только добавляются; UPDATE/DELETE запрещены (D9); число записей монотонно не убывает | При каждой попытке записи |
| Действия только своей ролью | `Оператор` | I18: заявку создаёт и залог вносит клиент; обработку, выдачу, приём, дефекты, записи и возврат залога — оператор; I19: у мастера ≥ 1 типа инструмента, у типа ≥ 1 единица | При вызове операций и при заведении типов/единиц |

## Состояния и переходы

### Заявка (D2)

| Переход | Кто инициирует | Условие |
|---|---|---|
| `* → ОжидаетОбработки` | Клиент | оставляет заявку (имя, телефон, тип, срок ≤ 14 суток) |
| `ОжидаетОбработки → ЗалогВнесён` | Клиент | внесён полный залог по типу |
| `ОжидаетОбработки → Отклонена` | Оператор | решение об отказе |
| `ЗалогВнесён → Обработана` | Оператор | данные и срок корректны |
| `ЗалогВнесён → Отклонена` | Оператор | решение об отказе; залог возвращается целиком |
| `Обработана → Закрыта` | Оператор | состоялась выдача инструмента |
| `Отклонена → ЗалогВозвращён` | Оператор | возврат полного залога (если вносился) |

### Единица инструмента (D12)

| Переход | Кто инициирует | Условие |
|---|---|---|
| `* → Свободен` | Оператор | заведение единицы или завершение ремонта |
| `Свободен → В аренде` | Оператор | выдача по заявке, осмотр без дефектов |
| `В аренде → Свободен` | Оператор | приём, дефектов нет |
| `В аренде → Неисправен` | Оператор | приём с дефектом |
| `Свободен → Неисправен` | Оператор | дефект выявлен при проверке |
| `Неисправен → Списан` | Оператор | не подлежит ремонту |

### Аренда (D6, D13)

| Переход | Кто инициирует | Условие |
|---|---|---|
| `* → Активна` | Оператор | выдача: залог + оплата + заявка `Обработана` |
| `Активна → Завершена` | Оператор | приём инструмента |
| `Завершена → [*]` (полный возврат) | Оператор | дефектов нет — залог возвращается целиком, одним действием |
| `Завершена → ЧастичныйВозврат → [*]` | Оператор | дефект есть — удержание `S`, возврат остатка |

## Операции и контракты

Формат: предусловие → постусловие (Мейер, «проектирование по контракту»).

| Операция | Владелец | Контракт: предусловие → постусловие |
|---|---|---|
| `СоздатьЗаявку` | `Заявка` | названы имя, телефон, тип и срок (1–14 суток) → заявка существует в статусе `ОжидаетОбработки`, создана запись журнала |
| `ВнестиЗалог` | `Залог` | заявка `ОжидаетОбработки`, залог ещё не внесён → залог равен `размерЗалога` типа, признак «внесён» = true, заявка `ЗалогВнесён`, запись в журнале |
| `ОбработатьЗаявку` | `Заявка` | заявка `ЗалогВнесён` → заявка `Обработана` либо `Отклонена` (I11), запись в журнале |
| `ОтклонитьЗаявку` | `Заявка` | статус ∈ {`ОжидаетОбработки`, `ЗалогВнесён`} → статус `Отклонена`; если залог внесён — выполнен единственный его возврат (I6, D7); запись в журнале |
| `ВыдатьИнструмент` | `Аренда` | заявка `Обработана` ∧ залог внесён ∧ оплата принята (I5) ∧ выбрана единица `Свободен` (I3) ∧ осмотр без дефектов (D11) → аренда `Активна` (датаВыдачи = сейчас), единица `В аренде` (I1, I2), заявка `Закрыта` (I12), стоимость = ставка × сутки (I8), записи: выдача, оплата |
| `ПродлитьАренду` | `Аренда` | аренда `Активна`, новые дата окончания ≤ выдача + 21 сутки (D3) → датаВозврата увеличена, стоимость пересчитана (I8), запись в журнале |
| `ЗафиксироватьДефект` | `Дефект` | выполнен осмотр (выдача или приём), обнаружено повреждение → создана запись `Дефект` с `суммаУщерба ≤ размерЗалога` (I14) |
| `ПринятьИнструмент` | `Аренда` | аренда `Активна` на эту единицу, выполнен осмотр (D11) → аренда `Завершена` (датаВозврата = сейчас); единица `Свободен` (дефектов нет) или `Неисправен` (дефект есть); возврат залога выполнен одним действием: полный либо остаток после удержания `S` (I7, I15, D13); записи: приём, возврат залога |
| `ЗаписатьВЖурнал` | `Запись` | вызвана любой операцией выше → добавлена новая запись; предыдущие записи не изменяются (I17) |

Проверка ролей (I18) — на входе в каждую операцию: `СоздатьЗаявку`/`ВнестиЗалог` — только от имени клиента; остальные — только оператором.
